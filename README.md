# Simple Property Manager

Simple site meant to be hosted on a local device (no online connection needed) Built on the following stack:

Frontend: React Backend: Node.js Database: SQLite

Features: 

=View list of properties

=Tenant Name 

=Rent received 

=toggle Notes

=add/remove/archive properties

## Startup

To initialize, you need 2 terminals open at the same time

### Terminal 1

cd backend

npm install -D tsx (only need this first run)

npx tsx server.ts

### Terminal 2

cd frontend 

npm run dev
